# NNM Meeting time across time zones

Deciding meeting time across time zones can be a [challenging task](https://anders.nemonisimors.com/timeZones), and it may be hard to understand how it affects the different participants.

This colorful tool will help you understand and visualize many of these uncertainties.

The official [*NNM Meeting time across time zones*](https://anders.nemonisimors.com/projects/meetingTime/) tool.
